# asteroids
## Description
An [Asteroids](https://en.wikipedia.org/wiki/Asteroids_(video_game)) game clone using python. This project is one of the guided projects in [boot.dev](https://www.boot.dev/courses/build-asteroids-python)

## How to Use This Project
Run shell below to download the project:
```bash
git clone https://github.com/zulkou/asteroids.git
cd asteoids
pip install -r requirements.txt
```
Or if you want to install the requirement inside virtual environtment, you need to activate the virtual environtment before executing `requirements.txt`.
## How to Play The Game
To run it, run this shell command:
```
python3 -m main
```
use `A`, `W`, `S`, `D` to move, and `space` to shoot. Enjoy!
